# DevEnv Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build DevEnv — a Tauri background agent + Next.js web dashboard that lets engineering managers set a "golden config" for their team's dev environment and see every engineer's compliance in real time.

**Architecture:** Lightweight Tauri tray agent scans each engineer's Mac (runtimes, venvs, PATH, global packages) and POSTs a MachineSnapshot to a Next.js API route every 15 minutes. The API stores snapshots in Supabase, computes a ComplianceResult against the team's GoldenConfig, and updates the machine's health score. Manager sees a team health dashboard; engineer sees a personal checklist with exact fix commands.

**Tech Stack:** Next.js 14 (App Router), TypeScript, Tailwind CSS, Supabase (Postgres + magic-link auth), Stripe (seat-based billing), Tauri v2 (Rust backend + React tray UI), shadcn/ui.

## Global Constraints

- Mac-only for agent (no Windows/Linux in MVP)
- Agent is read-only — it never deletes or modifies files
- Full Disk Access required for agent scanning — prompt on first launch
- Minimum 3 seats for Team plan ($15/seat/month)
- No AI diagnosis in MVP — cut to v2
- No env var scanning in MVP — cut to v2
- No cleanup/deletion in MVP — cut to v2
- Magic link auth only (no password auth)
- Supabase free tier compatible for early stage

## Review Focus

- **Version manager detection on a clean Mac:** `which python` may return `/usr/bin/python3` (system) even when pyenv is installed but not activated. The fix command generator must not recommend `pyenv install` if pyenv itself isn't installed.
- **Concurrent syncs from the same machine:** If an engineer triggers a manual resync while the 15-minute timer fires, two POSTs to `/api/sync` could create duplicate snapshots. The sync endpoint must be idempotent within a short window.
- **Golden config with zero required rules:** `computeHealthScore` divides by `requiredRules.length` — must return 100 (not NaN) when no required rules exist.
- **Invite token expiry:** Tokens expire after 7 days. The invite acceptance page must check `expires_at` and show a clear error, not a 500 or blank page.
- **Stripe seat count vs. actual user count:** If an engineer is removed from the team but Stripe proration hasn't run yet, `seat_count` in the DB could be out of sync with Stripe. All seat count reads for UI must come from the DB, not Stripe, and the webhook handler must be the single source of truth for reconciliation.

  created_at timestamptz not null default now()
);

-- Invite tokens
create table invites (
  id uuid primary key default gen_random_uuid(),
  token text unique not null default gen_random_uuid()::text,
  org_id uuid not null references organizations(id),
  created_by uuid not null references auth.users(id),
  used_by uuid references auth.users(id),
  used_at timestamptz,
  expires_at timestamptz not null default (now() + interval '7 days'),
  created_at timestamptz not null default now()
);

-- Machines (one per engineer)
create table machines (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id),
  org_id uuid not null references organizations(id),
  hostname text not null,
  os_version text,
  last_synced_at timestamptz,
  health_score integer,
  created_at timestamptz not null default now(),
  unique(user_id)
);

-- Machine snapshots (JSONB for schema flexibility)
create table machine_snapshots (
  id uuid primary key default gen_random_uuid(),
  machine_id uuid not null references machines(id),
  scanned_at timestamptz not null,
  runtimes jsonb not null default '[]',
  venvs jsonb not null default '[]',
  global_packages jsonb not null default '[]',
  path_entries jsonb not null default '[]',
  heavy_folders jsonb not null default '[]',
  created_at timestamptz not null default now()
);
create index on machine_snapshots(machine_id, scanned_at desc);

-- Golden configs (one per org, upserted)
create table golden_configs (
  id uuid primary key default gen_random_uuid(),
  org_id uuid not null unique references organizations(id),
  updated_by uuid references auth.users(id),
  rules jsonb not null default '[]',
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);

-- Compliance results (latest per machine)
create table compliance_results (
  id uuid primary key default gen_random_uuid(),
  machine_id uuid not null references machines(id),
  golden_config_id uuid not null references golden_configs(id),
  computed_at timestamptz not null default now(),
  passing jsonb not null default '[]',
  failing jsonb not null default '[]',
  warnings jsonb not null default '[]',
  unique(machine_id)
);

-- RLS policies
alter table organizations enable row level security;
alter table user_profiles enable row level security;
alter table invites enable row level security;
alter table machines enable row level security;
alter table machine_snapshots enable row level security;
alter table golden_configs enable row level security;
alter table compliance_results enable row level security;

-- Profiles: users see their own
create policy "users see own profile" on user_profiles
  for select using (auth.uid() = id);

-- Machines: users see machines in their org
create policy "org members see machines" on machines
  for select using (
    org_id in (select org_id from user_profiles where id = auth.uid())
  );

-- Compliance: same as machines
create policy "org members see compliance" on compliance_results
  for select using (
    machine_id in (select id from machines where org_id in (
      select org_id from user_profiles where id = auth.uid()
    ))
  );

-- Golden config: org members can read
create policy "org members read golden config" on golden_configs
  for select using (
    org_id in (select org_id from user_profiles where id = auth.uid())
  );

import type { MachineSnapshot, GoldenConfig, GoldenRule, ComplianceResult } from '@/types'

function resolveToolVersion(snapshot: MachineSnapshot, tool: string): string | null {
  const runtime = snapshot.runtimes.find(r => r.name === tool)
  if (runtime) return runtime.version
  const pkg = snapshot.global_packages.find(p => p.name === tool)
  if (pkg) return pkg.version
  return null
}

function versionSatisfies(actual: string, required: string): boolean {
  return actual.startsWith(required)
}

export function computeCompliance(
  snapshot: MachineSnapshot,
  config: GoldenConfig
): ComplianceResult {
  const passing: GoldenRule[] = []
  const failing: GoldenRule[] = []
  const warnings: GoldenRule[] = []

  for (const rule of config.rules) {
    const actual = resolveToolVersion(snapshot, rule.tool)

    if (actual === null) {
      rule.required ? failing.push(rule) : warnings.push(rule)
      continue
    }

    if (rule.required_version && !versionSatisfies(actual, rule.required_version)) {
      rule.required ? failing.push(rule) : warnings.push(rule)
      continue
    }

    passing.push(rule)
  }

  return { passing, failing, warnings }
}

export function computeHealthScore(
  result: ComplianceResult,
  config: GoldenConfig
): number {
  const requiredRules = config.rules.filter(r => r.required)
  if (requiredRules.length === 0) return 100
  const passingRequired = result.passing.filter(r => r.required).length
  return Math.round((passingRequired / requiredRules.length) * 100)
}
```

import type { GoldenRule, MachineSnapshot, Runtime } from '@/types'

function detectManager(snapshot: MachineSnapshot, tool: string): Runtime['manager'] | null {
  const runtime = snapshot.runtimes.find(r => r.name === tool)
  return runtime?.manager ?? null
}

type CommandGenerator = (version: string | null, manager: Runtime['manager'] | null) => string

const GENERATORS: Record<string, CommandGenerator> = {
  python: (version, manager) => {
    const v = version ?? '3.11'
    if (manager === 'pyenv') return `pyenv install ${v} && pyenv global ${v}`
    if (manager === 'conda') return `conda install python=${v}`
    return `brew install pyenv && pyenv install ${v} && pyenv global ${v}`
  },
  node: (version, manager) => {
    const v = version ?? '20'
    if (manager === 'nvm') return `nvm install ${v} && nvm use ${v} && nvm alias default ${v}`
    return `brew install nvm && nvm install ${v} && nvm use ${v}`
  },
  go: (version) => version ? `brew install go@${version}` : 'brew install go',
  rust: () => 'rustup update stable',
  ruby: (version, manager) => {
    const v = version ?? '3.3'
    if (manager === 'rbenv') return `rbenv install ${v} && rbenv global ${v}`
    return `brew install rbenv && rbenv install ${v} && rbenv global ${v}`
  },
}

export function getFixCommand(rule: GoldenRule, snapshot: MachineSnapshot): string {
  const generator = GENERATORS[rule.tool]
  if (generator) {
    const manager = detectManager(snapshot, rule.tool)
    return generator(rule.required_version, manager)
  }
  return `brew install ${rule.tool}`
}
```

import { NextResponse, type NextRequest } from 'next/server'

export async function middleware(request: NextRequest) {
  let supabaseResponse = NextResponse.next({ request })

  const supabase = createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    {
      cookies: {
        getAll() { return request.cookies.getAll() },
        setAll(cookiesToSet) {
          cookiesToSet.forEach(({ name, value }) => request.cookies.set(name, value))
          supabaseResponse = NextResponse.next({ request })
          cookiesToSet.forEach(({ name, value, options }) =>
            supabaseResponse.cookies.set(name, value, options)
          )
        },
      },
    }
  )

  const { data: { user } } = await supabase.auth.getUser()

  const isAppRoute = request.nextUrl.pathname.startsWith('/dashboard') ||
    request.nextUrl.pathname.startsWith('/me') ||
    request.nextUrl.pathname.startsWith('/config')

  if (!user && isAppRoute) {
    return NextResponse.redirect(new URL('/login', request.url))
  }

  return supabaseResponse
}

import { isInviteValid } from './helpers'

export async function GET(
  _request: Request,
  { params }: { params: Promise<{ token: string }> }
) {
  const { token } = await params
  const supabase = await createClient()

  const { data: invite } = await supabase
    .from('invites')
    .select('*, organizations(name)')
    .eq('token', token)
    .single()

  if (!invite) return NextResponse.json({ valid: false, error: 'Invite not found' }, { status: 404 })

  const valid = isInviteValid(invite)
  return NextResponse.json({
    valid,
    org_name: valid ? (invite.organizations as any).name : null,
    expires_at: invite.expires_at,
  })

export async function POST(
  _request: Request,
  { params }: { params: Promise<{ token: string }> }
) {
  const { token } = await params
  const supabase = await createClient()
  const { data: { user } } = await supabase.auth.getUser()
  if (!user) return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })

  const { data: invite } = await supabase
    .from('invites')
    .select('*')
    .eq('token', token)
    .single()

  if (!invite || !isInviteValid(invite)) {
    return NextResponse.json({ error: 'Invalid or expired invite' }, { status: 400 })

  // Mark invite used
  await supabase
    .from('invites')
    .update({ used_by: user.id, used_at: new Date().toISOString() })
    .eq('id', invite.id)

  // Set user as engineer in org
  await supabase
    .from('user_profiles')
    .update({ org_id: invite.org_id, role: 'engineer' })
    .eq('id', user.id)

  // Increment seat count
  await supabase.rpc('increment_seat_count', { org_id: invite.org_id })

  return NextResponse.json({ success: true })
}

'use client'
import { useState } from 'react'
import type { GoldenRule } from '@/types'
import { Button } from '@/components/ui/button'
import { Input } from '@/components/ui/input'

const KNOWN_TOOLS = ['python', 'node', 'go', 'rust', 'ruby', 'awscli', 'terraform', 'kubectl', 'docker']

type Props = {
  initialRules: GoldenRule[]
  onSave: (rules: GoldenRule[]) => Promise<void>
}

export function GoldenConfigForm({ initialRules, onSave }: Props) {
  const [rules, setRules] = useState<GoldenRule[]>(initialRules)
  const [saving, setSaving] = useState(false)
  const [newTool, setNewTool] = useState('')
  const [newVersion, setNewVersion] = useState('')

  function addRule() {
    if (!newTool.trim()) return
    const tool = newTool.trim().toLowerCase()
    if (rules.find(r => r.tool === tool)) return
    setRules(prev => [...prev, { tool, required_version: newVersion.trim() || null, required: true }])
    setNewTool('')
    setNewVersion('')
  }

  function removeRule(tool: string) {
    setRules(prev => prev.filter(r => r.tool !== tool))
  }

  function toggleRequired(tool: string) {
    setRules(prev => prev.map(r => r.tool === tool ? { ...r, required: !r.required } : r))
  }

  async function handleSave() {
    setSaving(true)
    await onSave(rules)
    setSaving(false)
  }

  return (
    <div className="space-y-6">
      <div className="space-y-2">
        {rules.map(rule => (
          <div key={rule.tool} className="flex items-center gap-3 p-3 border rounded-lg">
            <span className="font-mono font-medium w-28">{rule.tool}</span>
            <span className="text-sm text-muted-foreground flex-1">
              {rule.required_version ?? 'any version'}
            </span>
            <button
              onClick={() => toggleRequired(rule.tool)}
              className={`text-xs px-2 py-1 rounded ${rule.required ? 'bg-red-100 text-red-700' : 'bg-yellow-100 text-yellow-700'}`}
            >
              {rule.required ? 'Required' : 'Recommended'}
            </button>
            <button onClick={() => removeRule(rule.tool)} className="text-muted-foreground hover:text-destructive">×</button>
          </div>
        ))}
      </div>

      <div className="flex gap-2">
        <Input
          list="known-tools"
          placeholder="Tool (e.g. python)"
          value={newTool}
          onChange={e => setNewTool(e.target.value)}
          className="w-40"
        />
        <datalist id="known-tools">
          {KNOWN_TOOLS.map(t => <option key={t} value={t} />)}
        </datalist>
        <Input
          placeholder="Version (e.g. 3.11)"
          value={newVersion}
          onChange={e => setNewVersion(e.target.value)}
          className="w-32"
        />
        <Button variant="outline" onClick={addRule} type="button">Add rule</Button>
      </div>

      <Button onClick={handleSave} disabled={saving}>
        {saving ? 'Saving…' : 'Save golden config'}

export async function POST(request: Request) {
  const authHeader = request.headers.get('authorization')
  if (!authHeader?.startsWith('Bearer ')) {
    return NextResponse.json({ error: 'Unauthorized' }, { status: 401 })
  }

  const jwt = authHeader.slice(7)

  // Verify JWT and get user
  const { data: { user }, error: authError } = await adminSupabase.auth.getUser(jwt)
  if (authError || !user) {
    return NextResponse.json({ error: 'Invalid token' }, { status: 401 })
  }

  const body: MachineSnapshot & { hostname: string; os_version: string } = await request.json()

  // Upsert machine record
  const { data: machine, error: machineError } = await adminSupabase
    .from('machines')
    .upsert(
      { user_id: user.id, hostname: body.hostname, os_version: body.os_version,
        org_id: await getOrgId(user.id), last_synced_at: body.scanned_at },
      { onConflict: 'user_id' }
    )
    .select()
    .single()

  if (machineError || !machine) {
    return NextResponse.json({ error: 'Machine upsert failed' }, { status: 500 })
  }

  // Store snapshot
  await adminSupabase
    .from('machine_snapshots')
    .insert(buildSnapshotRecord(machine.id, body))

  // Compute and store compliance
  const { data: config } = await adminSupabase
    .from('golden_configs')
    .select('*')
    .eq('org_id', machine.org_id)
    .single()

  let healthScore = null

  if (config && config.rules.length > 0) {
    const result = computeCompliance(body, config)
    healthScore = computeHealthScore(result, config)

    await adminSupabase
      .from('compliance_results')
      .upsert({
        machine_id: machine.id,
        golden_config_id: config.id,
        computed_at: new Date().toISOString(),
        passing: result.passing,
        failing: result.failing,
        warnings: result.warnings,
      }, { onConflict: 'machine_id' })

    await adminSupabase
      .from('machines')
      .update({ health_score: healthScore })
      .eq('id', machine.id)
  }

  return NextResponse.json({ machine_id: machine.id, health_score: healthScore })
}

async function getOrgId(userId: string): Promise<string> {
  const { data } = await adminSupabase
    .from('user_profiles')
    .select('org_id')
    .eq('id', userId)
    .single()
  return data?.org_id
}

```typescript
import { stripe } from '@/lib/stripe'
import { createClient } from '@supabase/supabase-js'
import { NextResponse } from 'next/server'
import type Stripe from 'stripe'

const adminSupabase = createClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY!
)

export async function POST(request: Request) {
  const body = await request.text()
  const sig = request.headers.get('stripe-signature')!

  let event: Stripe.Event
  try {
    event = stripe.webhooks.constructEvent(body, sig, process.env.STRIPE_WEBHOOK_SECRET!)
  } catch {
    return NextResponse.json({ error: 'Webhook signature invalid' }, { status: 400 })
  }

  if (event.type === 'customer.subscription.updated') {
    const subscription = event.data.object as Stripe.Subscription
    const orgId = subscription.metadata?.org_id ?? await getOrgIdFromCustomer(subscription.customer as string)
    if (orgId) {
      await adminSupabase
        .from('organizations')
        .update({
          stripe_subscription_id: subscription.id,
          seat_count: subscription.items.data[0].quantity ?? 3,
        })
        .eq('id', orgId)
    }
  }

  if (event.type === 'customer.subscription.deleted') {
    const subscription = event.data.object as Stripe.Subscription
    const orgId = await getOrgIdFromCustomer(subscription.customer as string)
    if (orgId) {
      await adminSupabase
        .from('organizations')
        .update({ stripe_subscription_id: null })
        .eq('id', orgId)
    }
  }

  return NextResponse.json({ received: true })
}

async function getOrgIdFromCustomer(customerId: string): Promise<string | null> {
  const customer = await stripe.customers.retrieve(customerId)
  if (customer.deleted) return null
  return (customer as Stripe.Customer).metadata?.org_id ?? null
}

use std::process::Command;
use which::which;
use crate::types::Runtime;

pub fn parse_version_output(output: &str) -> Option<String> {
    let trimmed = output.trim();
    if trimmed.is_empty() { return None; }
    // Strip leading 'v' or 'Python ' prefix
    let cleaned = trimmed
        .trim_start_matches("Python ")
        .trim_start_matches('v');
    // Extract first semver-like token
    cleaned.split_whitespace().next().map(|s| s.to_string())
}

fn run_version_cmd(cmd: &str, args: &[&str]) -> Option<String> {
    Command::new(cmd)
        .args(args)
        .output()
        .ok()
        .and_then(|o| {
            let out = String::from_utf8_lossy(&o.stdout).to_string();
            let err = String::from_utf8_lossy(&o.stderr).to_string();
            parse_version_output(if out.trim().is_empty() { &err } else { &out })
        })
}

fn detect_python_manager() -> &'static str {
    if which("pyenv").is_ok() { return "pyenv"; }
    if which("conda").is_ok() { return "conda"; }
    "system"
}

fn detect_node_manager() -> &'static str {
    // nvm sets NVM_DIR env var
    if std::env::var("NVM_DIR").is_ok() { return "nvm"; }
    if which("volta").is_ok() { return "volta"; }
    "system"
}

pub fn detect_runtimes() -> Vec<Runtime> {
    let mut runtimes = Vec::new();

    let tools: Vec<(&str, Vec<&str>, fn() -> &'static str)> = vec![
        ("python3", vec!["--version"], || detect_python_manager()),
        ("node", vec!["--version"], || detect_node_manager()),
        ("go", vec!["version"], || "system"),
        ("rustc", vec!["--version"], || "rustup"),
        ("ruby", vec!["--version"], || "system"),
    ];

    for (cmd, args, manager_fn) in tools {
        if let (Ok(path), Some(version)) = (
            which(cmd),
            run_version_cmd(cmd, &args),
        ) {
            let name = match cmd {
                "python3" => "python",
                "rustc" => "rust",
                other => other,
            };
            runtimes.push(Runtime {
                name: name.to_string(),
                version,
                manager: manager_fn().to_string(),
                path: path.to_string_lossy().to_string(),
            });
        }
    }

    runtimes
}

fn read_pyvenv_cfg(venv_path: &Path) -> Option<String> {
    let cfg = venv_path.join("pyvenv.cfg");
    let contents = fs::read_to_string(cfg).ok()?;
    for line in contents.lines() {
        if line.starts_with("version") {
            return line.split('=').nth(1).map(|s| s.trim().to_string());
        }
    }
    None
}

fn dir_size_mb(path: &Path) -> f64 {
    WalkDir::new(path)
        .into_iter()
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_file())
        .filter_map(|e| e.metadata().ok())
        .map(|m| m.len())
        .sum::<u64>() as f64 / 1_048_576.0
}

fn is_venv(path: &Path) -> bool {
    path.join("pyvenv.cfg").exists() && path.join("bin").join("python").exists()
}

pub fn find_venvs() -> Vec<Venv> {
    let home = dirs::home_dir().unwrap_or_else(|| PathBuf::from("/"));
    let mut venvs = Vec::new();

    // Search home dir up to depth 5 for venv dirs
    for entry in WalkDir::new(&home)
        .max_depth(5)
        .follow_links(false)
        .into_iter()
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_dir())
    {
        let path = entry.path();
        if is_venv(path) {
            let python_version = read_pyvenv_cfg(path).unwrap_or_else(|| "unknown".to_string());
            let size_mb = dir_size_mb(path);
            venvs.push(Venv {
                path: path.to_string_lossy().to_string(),
                python_version,
                size_mb: (size_mb * 10.0).round() / 10.0,
                last_used_at: None,
            });
        }
    }

    venvs
}

pub fn parse_path() -> Vec<PathEntry> {

const HEAVY_PATTERNS: &[&str] = &[
    "node_modules",
    "__pycache__",
    ".gradle",
    "DerivedData",
    ".tox",
    "dist",
    ".next",

pub fn find_heavy_folders() -> Vec<HeavyFolder> {

        .filter(|e| e.file_type().is_dir())

                size_mb: (size_mb * 10.0).round() / 10.0,

async fn run_sync(app: AppHandle) {
    let cfg = config::AgentConfig::load();
    if cfg.jwt.is_none() { return; }

    let hostname = hostname::get()
        .map(|h| h.to_string_lossy().to_string())
        .unwrap_or_else(|_| "unknown".to_string());
    let os_version = format!("macOS {}", std::env::var("MACOS_VERSION").unwrap_or_default());

    let snapshot = scanner::scan(hostname, os_version);

    match sync::post_snapshot(&snapshot, &cfg).await {
        Ok(res) => {
            let mut updated_cfg = cfg;
            updated_cfg.machine_id = Some(res.machine_id);
            updated_cfg.save();

            let issue_count = res.health_score
                .map(|s| if s < 100 { 1u32 } else { 0u32 })
                .unwrap_or(0);

        Err(e) => eprintln!("Sync error: {e}"),

    )
  }

  return (
    <div className="p-6 max-w-sm">
      <h1 className="text-xl font-bold mb-4">Set up DevEnv agent</h1>
      <p className="text-sm text-gray-600 mb-4">
        Paste your session token from the DevEnv web app.
      </p>
      <form onSubmit={handleSetup} className="space-y-4">
        <textarea
          className="w-full border rounded p-2 text-xs font-mono h-24"
          placeholder="Paste your token here"
          value={jwt}
          onChange={e => setJwt(e.target.value)}
          required
        />
        <button
          type="submit"
          disabled={saving}
          className="w-full bg-black text-white rounded py-2"
        >
          {saving ? 'Connecting…' : 'Connect'}
        </button>
      </form>
    </div>
  )
}
```
